# Code of Conduct

This project welcomes contributors of every background. To keep the space useful and respectful, the following rules apply to all participants — maintainers, contributors, reviewers, and users — across the issue tracker, pull requests, discussions, and any other project channels.

## Expected behavior

- Be respectful. Critique code and ideas, not people.
- Assume good faith. Ask before escalating.
- Keep discussion technical and on-topic for the issue or thread.
- Credit prior work. Cite sources for ported code, prompts, or designs.

## Unacceptable behavior

- Personal attacks, harassment, or discriminatory language.
- Sustained disruption, off-topic flooding, or bad-faith argument.
- Sharing other people's private information without permission.
- Posting secrets, credentials, or proprietary content you do not have the right to share.

## Enforcement

Report violations privately via GitHub Security Advisory:

**https://github.com/iVersatile/Prompiler/security/advisories/new**

Maintainers will review reports as soon as practical, keep reporter identity confidential to the extent allowed, and respond with one of:

- No action — concern does not meet the bar.
- Private warning — behavior must stop.
- Temporary restriction — limited interaction with the project for a stated period.
- Permanent removal — banned from project channels.

Maintainers may act without a report when behavior is publicly visible and clearly violates this document. Decisions are final at the maintainer's discretion; appeal by replying to the original advisory thread.

## Scope

This Code applies to all project spaces and to public conduct that materially affects the project (for example, harassing a contributor on another platform about their participation here).
